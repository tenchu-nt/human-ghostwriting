# Human Ghostwriting

Makes AI write like a person instead of like a press release.

To install by hand, drag this whole folder into `~/.claude/skills` (or
`~/.codex/skills`), then restart the app. For ChatGPT, see `CHATGPT.md`.

Full instructions and the one-command install:
https://github.com/tenchu-nt/human-ghostwriting
