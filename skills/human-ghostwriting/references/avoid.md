# Anti-Slop Reference: Words, Phrases, and Text Patterns to Review

These are review signals, not a universal blacklist. A word can be accurate in
a technical, legal, or quoted context. The problem is usually empty emphasis,
vagueness, or a phrase doing social signalling instead of communicating. Keep
the precise word when it is genuinely the best one.

## 1. Inflated language

Review these when they make a claim sound larger than the evidence:

| Review signal | Usually clearer as |
| --- | --- |
| groundbreaking, revolutionary, game-changing | State the specific change or result. |
| transformative, powerful, remarkable | Name what changed, for whom, and by how much. |
| cutting-edge, state-of-the-art | Name the capability, method, or version. |
| seamless, effortless, frictionless | Describe the steps removed or the time saved. |
| robust, comprehensive | Specify scope, reliability, or test condition. |
| world-class, best-in-class, industry-leading | Provide comparative evidence or remove. |
| unlock, supercharge, elevate | Say enable, improve, reduce, or state the outcome. |
| pivotal, crucial, paramount | Explain the consequence. |
| delve, delving | look at, examine, go through |
| tapestry, mosaic, symphony | Name the actual thing. |
| a testament to | State what happened and why it matters. |
| underscores, underpins, highlights | shows, supports, causes |
| boasts, features, offers | has, includes |
| vibrant, intricate, meticulous, nuanced | Name the detail you mean. |
| unprecedented, profound, stunning | Give the comparison or the number. |

## 2. Corporate and consultant language

Use the plainer option unless the audience expects specialist terminology.

| Review signal | Usually clearer as |
| --- | --- |
| leverage, utilise | use |
| facilitate | help, enable, arrange |
| navigate a challenge | handle a problem |
| deep dive | analysis, review |
| landscape | market, situation, field |
| synergy | how the parts work together |
| touch base, circle back | speak again, return to this |
| moving forward | next, from now |
| pain points | problems, frustrations, costs |
| value-add | useful, extra value, specific benefit |
| stakeholder alignment | agreement between named people or teams |
| optimise | improve a named measure |

## 3. Common AI-shaped openings and transitions

Cut these when they only announce that a point is coming:

- "In today's fast-paced world..." / "In an era where..."
- "Navigating the complexities of..."
- "It is important to note that..."
- "It is worth noting that..."
- "When it comes to..."
- "At its core..."
- "Let us dive into..."
- "Here is the thing..."
- "The uncomfortable truth is..."
- "Without further ado..."
- "In conclusion..."
- "At the end of the day..."
- "Moreover", "Furthermore", "Additionally", and "Importantly" as default
  paragraph openers.

Start with the claim, fact, observation, or request instead.

## 4. Formulae that manufacture depth

Review and normally rewrite these shapes:

| Pattern | More direct direction |
| --- | --- |
| "It is not X. It is Y." | State Y, unless correcting a real error. |
| "Not just X, but Y." | Say what Y adds. |
| "The question is not X, it is Y." | Answer the real question directly. |
| "Stop X. Start Y." | Explain the change and why it is warranted. |
| "X is dead. Y is the future." | Give the evidence and limit the claim. |
| "The truth: ..." | State the fact without a reveal. |
| "Read that again." | Let the point stand on its own. |
| "This changes everything." | Say what actually changes. |

## 5. Vague claims and false agency

| Review signal | Better direction |
| --- | --- |
| "The stakes are high." | Name the cost, decision, or deadline. |
| "The implications are significant." | Explain the consequence. |
| "The data tells us..." | Say who analysed the data and what it shows. |
| "The market rewards..." | Say what buyers pay for or choose. |
| "The conversation is shifting..." | Name the people, change, and evidence. |
| "This is a testament to..." | State what happened and why it matters. |

## 6. Distance and evasion

**Narrator from a distance.** Put the reader in the room rather than floating
above it.

| Review signal | Better direction |
| --- | --- |
| "Nobody designed this." | "You do not sit down one day and decide to..." |
| "People tend to..." | Address the reader directly. |
| "This happens because..." | Name the cause and who it affects. |

**Wh- sentence openers.** Lead with the subject or the verb instead.

| Review signal | Better direction |
| --- | --- |
| "What makes this hard is..." | "The constraint is X." |
| "Why this matters is..." | State the consequence. |
| "How I approach this is..." | "I approach this by..." |

**Bloated copulatives.** "serves as", "stands as", "represents a", "plays a role
in" become is, has, uses, gives, shows. Watch the reverse trap too: plain "is"
and "has" are often correct and should not be inflated into an active verb to
sound energetic.

**Negative listing.** "Not a consultant. Not a coach. A builder." becomes "I
build things."

## 7. Metaphors that hide rather than explain

Avoid stock imagery for ordinary business or product ideas: journey, north
star, flywheel, ecosystem, engine, bridge, lens, blueprint, iceberg,
scaffolding, and "the X of Y". Use a metaphor only when the literal version
would be less clear, the comparison is accurate, and the audience will grasp
it immediately.

Also review physical-craft verbs applied to abstract work: "weaved together",
"distilled", "unpacked", "baked in", "anchored", "mapped", and "sharpened".
Often, chose, removed, added, explained, compared, or measured says more.

## 8. Formatting and rhythm tells

- Three identical paragraphs with the same topic-sentence pattern.
- Three short declarative sentences used for drama rather than meaning.
- A list of three selected because it sounds complete, not because there are
  exactly three items.
- A rhetorical question followed by the obvious answer.
- A summary after every paragraph.
- Excessive one-line paragraphs, bold text, headings, emoji bullets, hashtags,
  exclamation marks, or ellipses.
- Markdown markers in an email, text message, or other plain-text channel.

Vary structure because the thought requires it, not to randomise the prose.

## 9. Typography tells

The em dash rule is absolute and lives in SKILL.md. These are the rest:

- Emoji used as section headers or as every bullet point.
- Mixed straight and curly quotation marks or apostrophes in one piece, which
  usually means the text was assembled from two sources.
- Bold applied to a phrase in the middle of a sentence for emphasis the words
  should be carrying.
- Title Case Applied To Ordinary Headings.
- A bulleted list where two sentences would read better.

## 10. Empty closing lines

Review endings such as "That is the real lesson", "And that changes
everything", "The future is yours", or "The rest will follow". End on the
last specific sentence that has already earned the finish.
